## ダウンロード・インストール

### 「Windows によって PC が保護されました」と出て、起動できない

このアプリには電子署名（有料の証明書）が付いていないため、Windows がこの画面を出します。
画面の **「詳細情報」** を押し、出てきた **「実行」** を押してください。

### ブラウザがダウンロードを止めてしまう

「一般的にダウンロードされていません」などと出るときは、Microsoft Edge なら
警告の右の「…」→「保存」→「詳細表示」→「保持する」でダウンロードできます。

### 「スマート アプリ コントロールによって…ブロックされました」と出る

Windows 11 の「スマート アプリ コントロール」がオンになっていると、電子署名のないアプリは起動できません。
今のところ、このアプリは署名をしていないため、この設定がオンのパソコンでは使えません。

### 「Microsoft Edge WebView2 ランタイムが入っていません」と出る

画面の表示に、Windows の部品「WebView2」を使っています。Windows 11 と、更新している Windows 10 には入っています。
メッセージの「はい」を押すとマイクロソフトのページが開くので、「エバーグリーン ブートストラップ」をダウンロードしてインストールしてから、もう一度起動してください。

### アンインストールしたい

Windows の「設定」→「アプリ」→「インストールされているアプリ」で「SR-MK1 for PC」を選び、「アンインストール」を押します。
zip 版は、フォルダを削除するだけです。

設定・印刷履歴・作りかけのラベルは、アンインストールしても残ります（入れ直したときにそのまま使えます）。
完全に消したいときは、エクスプローラーのアドレス欄に `%APPDATA%\SR-MK1 for PC` と入れて開き、そのフォルダを削除してください。

### 新しい版に更新したい

新しい版の `setup.exe` をダウンロードして、そのままインストールしてください。上書きで更新され、設定や履歴はそのまま残ります。

## つながらない

### 「はじめの設定」で SR-MK1 が見つからない

アプリは、**Windows にペアリング済み**の SR-MK1 を探します。先に Windows で SR-MK1 をペアリングしてください（[はじめかた › ペアリング](getting-started.md#4-sr-mk1-をパソコンにペアリングする)）。

- Windows の「デバイスの追加」に SR-MK1 が出てこないときは、SR-MK1 の電源を入れ直して、しばらく待ってください
- スマホとつながっている SR-MK1 は、パソコンから見つからないことがあります。スマホの Bluetooth をオフにしてください
- 名前が「SR-MK1」と違う形で登録されている場合は、「SR-MK1 以外の機器も表示する」にチェックを入れて選んでください

### 「未接続」のまま変わらない／「プリンタから返事がありません」と出る

次の順に確かめてください。

1. SR-MK1 の電源が入っているか
2. パソコンから離れすぎていないか（同じ机の上くらいが確実です）
3. **スマホのアプリが SR-MK1 につながったままになっていないか**（スマホの Bluetooth をオフに）
4. SR-MK1 の電源を入れ直して、アプリの「更新」を押す
5. それでもだめなら、Windows の Bluetooth の設定で SR-MK1 を「デバイスの削除」して、ペアリングからやり直す
   （アプリの「設定」→「プリンタ」→「プリンタを選び直す」）

### 「Bluetooth がオフになっているか、アダプタが見つかりません」と出る

Windows の「設定」→「Bluetooth とデバイス」で Bluetooth をオンにしてください。
USB の Bluetooth アダプタを使っている場合は、差し込まれているか確かめてください。

### スマホのアプリと両方で使いたい

使えます。ただし SR-MK1 は同時に 1 台としかつながらないので、パソコンで使うときはスマホの Bluetooth をオフにするか、スマホのアプリを閉じてください。
反対に、スマホで使うときは、このアプリを閉じてください。

## 印刷

### 印刷の途中で止まった

画面に止まった理由（テープがなくなった、カバーが開いている など）が出ます。
直してから **「続きから印刷」** を押すと、止まったラベルから印刷し直します。やめるときは「中止」を押します。

### 「テープの幅がラベルと合いません」と出る

作っているラベルのテープ幅と、プリンタに入っているテープが違います。
「中止」を押してから、ラベルに合うテープに入れ替えて、もう一度「印刷」を押してください。
今のテープのまま印刷したいときは、そのまま「印刷」を押し直します。プリンタにつながっていると、画面のラベルは入っているテープの幅に自動で合わせられます。

### 印刷ボタンが押せない

- 右上が「接続中」になっているか確かめてください
- テープが入っていない、エラーが出ている、ケーブル表示ラベル用テープが入っている、のどれかだと押せません
- ラベルに何も置いていないときも押せません

### ラベルの長さが少し違う／余白が左右で違う

機械ごとのわずかなずれです。「設定」→「寸法の補正」で直せます（[使い方 › 寸法の補正](usage.md#寸法の補正)）。

### 端の線が切れてしまう

ラベルの端ちょうどに引いた線は、カットのときに切れることがあります。「前後の余白」を 2mm 以上にしてください。

### バーコードが読み取れない

「太さ」を大きくすると読み取りやすくなります。12mm 以下の細いテープでは、内容を短くするか、24mm テープを使ってください。

### 印刷がかすれる／濃すぎる

印刷の欄の「濃度」で調整できます（−5〜+5）。

## そのほか

### 作ったラベルはどこに保存される？

- 「保存」を押したラベル: 自分で選んだ場所の `.json` ファイル
- 作りかけのラベル・設定・印刷履歴: `%APPDATA%\SR-MK1 for PC`（エクスプローラーのアドレス欄に入れると開けます）

### 使えるテープは？

12mm と 24mm は確認済みです。4mm、6mm、9mm、18mm は使えるはずですが、まだ確かめていません。
ケーブル表示ラベル用テープは使えません。くわしくは [できないこと・注意](limitations.md) をご覧ください。

### SR-MK1 以外のテプラでも使える？

SR-MK1 でしか確かめていません。ほかの機種はつながっても正しく印刷できるか分からないので、おすすめしません。

## 不具合を知らせる

このページで解決しないときは、GitHub のこのリポジトリの「Issues」から知らせてください。

1. アプリの「設定」→「困ったとき」を開く
2. **「診断情報をコピー」** を押す
3. Issue に、何をしたら・何が起きたかと一緒に貼り付ける

診断情報には、アプリの版、Windows の版、プリンタの状態、最近の動作の記録（ログ）が入っています。
プリンタの Bluetooth アドレスは後ろ半分を伏せてあります。名前やファイルの中身などは入りません。

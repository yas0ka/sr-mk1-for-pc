## 非公式のアプリです

- このアプリは個人が作ったもので、**株式会社キングジムとは関係ありません**。キングジムが作ったり、認めたりしたものではありません
- キングジムには問い合わせないでください。このアプリについての質問や不具合は、GitHub の Issues へお願いします
- SR-MK1 の通信の仕組みは公開されていないため、公開資料と実機での試行から作っています。
  プリンタ本体の更新などで、ある日使えなくなる可能性があります
- **無保証**です。使ったことで起きた不具合や損害（プリンタやテープを含む）について、作者は責任を負いません

## 動作を確かめた環境

| | |
|---|---|
| プリンタ | テプラ PRO SR-MK1（1 台） |
| パソコン | Windows 11 |
| Bluetooth | TP-Link UB400（USB アダプタ） |
| テープ | 12mm、24mm |

これ以外の組み合わせでも動くはずですが、確かめていません。うまく動いた・動かなかったという報告を歓迎します。

## テープ

| テープ | 状態 |
|---|---|
| 12mm、24mm | 実機で確認済み |
| 4mm、6mm、9mm、18mm | 使えるはずですが、まだ確かめていません（印字できる幅は資料の値を使っています） |
| ケーブル表示ラベル用テープ | **使えません**。プリンタに入っているとアプリが「未対応」と表示し、印刷しません |

- ラベルは 1 枚ごとに自動でカットされます（ハーフカットやカットなしは選べません）
- 余白なし（フチなし）の印刷はできません

## 純正のアプリ・ソフトとの違い

- 「テプラ クリエイター」や、スマホのアプリにある次の機能はありません
  - デザイン済みのテンプレート集、外枠・地紋
  - Excel・CSV の表から差し込んで連続印刷
  - 白黒反転、貼り合わせ印刷、翻訳
- 純正にない機能もあります（文字の自動サイズ、印刷履歴、続きから印刷、寸法の補正 など）

## そのほかの注意

- **Windows 専用**です（Mac・Linux では動きません）
- SR-MK1 は**同時に 1 台**としかつながりません。このアプリを使っている間は、スマホのアプリからはつながりません
- 印刷はプリンタの解像度（360dpi）で白黒にして送ります。細かい写真やグレーの濃淡は、点の濃さ（網点）で表します
- まだ実機で確かめていないこと
  - 縦置きラベルの実物の向き
  - 1 次元バーコードの読み取り（QR コードは確認済み）
  - テープ切れなど、実際のエラーが起きたときの表示と「続きから印刷」

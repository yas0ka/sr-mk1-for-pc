    はじめの設定

    1. はじめに
    2. ペアリング
    3. 接続テスト
    4. 完了

    SR-MK1 for PC は、キングジムのラベルプリンタ「テプラ PRO SR-MK1」を Windows パソコンから使うための非公式アプリです。

    まず、パソコンとプリンタをつなぐ設定をします (3 分ほど)。始める前に、次の 3 つを確かめてください。

    • SR-MK1 の電源を入れ、テープカートリッジを入れておく
    • パソコンの Bluetooth をオンにする
      Bluetooth が付いていないパソコンでは、USB の Bluetooth アダプタを使えます
    • スマホのアプリで SR-MK1 を使っていたら、スマホの Bluetooth をいったんオフにする
      SR-MK1 は同時に 1 台としかつながりません
    SR-MK1 をパソコンにペアリングする方法
    2. 「デバイスの追加」を押し、「Bluetooth」を選ぶ
    3. 一覧に「SR-MK1」が出てきたら選ぶ
      出てこないときは、SR-MK1 の電源を入れ直して少し待ってください
    4. 「接続済み」や「ペアリング済み」と出たら、この画面に戻って「もう一度探す」を押す

    テスト用のラベルを 1 枚印刷して、ちゃんと出てくるか確かめられます (なくても次へ進めます)。

    設定が終わりました

    • 右上の表示が「接続中」なら、すぐに印刷できます
    • 印刷したラベルの長さが少しずれるときは、「設定」→「寸法の補正」で合わせられます
    • プリンタを替えたときや、うまくつながらないときは「設定」から直せます

    寸法の補正

    プリンタによって、印刷したラベルの長さがわずかにずれることがあります (100mm が 98mm になる、など)。 目盛りのラベルを印刷して測ると、そのずれを直せます。

    今の補正:

    1. 目盛りのラベルを印刷する (長さ 約 11cm、補正なしで出ます)
    2. 定規で 3 か所を測って入れる
      ア0 ──── 目盛り ──── 100ウ
    3. 補正がうまくいったか、もう一度印刷して確かめる (イが 100mm、アとウが 5mm ならぴったり)

    画面の実寸

    編集画面で「表示: 実寸」にしたとき、画面上の大きさが本物と同じになるように合わせます。 下のバーを定規で測り、長さを入れてください (100mm になるのが正解)。

    困ったとき

    「未接続」のまま変わらない
    SR-MK1 の電源が入っているか、パソコンから離れすぎていないか確かめてください。 スマホのアプリがつながったままだと、パソコンからはつながりません (スマホの Bluetooth をオフに)。 それでもだめなら、SR-MK1 の電源を入れ直して「更新」を押してください。
    印刷の途中で止まった
    テープ切れやカバーの開きなど、表示された理由を直してから「続きから印刷」を押すと、止まったラベルから印刷し直します。
    ラベルの長さが少し違う
    「寸法の補正」で合わせられます。
    プリンタが一覧に出てこない
    先に Windows の Bluetooth の設定で SR-MK1 をペアリングしてください (「プリンタ」→「プリンタを選び直す」に手順があります)。

    ここにないことは、ホームページの「困ったとき」をご覧ください。
